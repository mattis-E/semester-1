# Current Projects
## CK2 WhoAmI [Private]
A Windows-only (currently) utility which reads save file data from Crusader Kings II games and enables the user to add their own custom notes, remarks, reminders; track family trees and descendants; and rate characters. It's mostly aimed to supplement the game's barebones Character Bookmark system by providing and saving a _reason_ for bookmarking a character.
